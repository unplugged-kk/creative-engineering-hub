# measured-sound-pass

Plan a licence-aware cue sheet and exported-file audio verification without downloading sounds or replacing Video Factory audio QA.

Version 0.1.0. Candidate, instruction-only guidance for an already available HyperFrames workflow.
No executable scripts, external downloads, fonts, audio or media are bundled.

Read SKILL.md for the workflow, references/provenance.md for source scope, and evals/cases.yaml for acceptance cases.
Run `uv run ceh skills validate measured-sound-pass` from CEH to validate structure. Do not interpret validation or installation
as agent execution, benchmark evidence or production approval.

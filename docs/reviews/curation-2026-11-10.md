# Creative capability curation - 2026-11-10

## Added candidate guidance

Two original instruction-only skills consolidate complementary ideas across existing research sources:

- `kinetic-type-planning` 0.1.0: exact-copy preservation, deterministic frame timing, readable holds and encoded-frame review.
  Research references: LottieFiles CEH-0018 and Charlie Hills CEH-0002.
- `measured-sound-pass` 0.1.0: rights-verified local asset inventory, cue planning, exported-file measurement and separate human
  listening review. Research references: Barty-Bart CEH-0004 and LottieFiles CEH-0018.

Each supplies SKILL.md, skill.yaml, README, VERSION notes, examples, evaluation cases, provenance and a scripts boundary note.
No executable scripts, upstream implementation, timing tables, sounds, fonts or images are copied. They are not catalog entries
and are not approved. They preserve existing VF skill precedence, runtime pins, director/render contracts and quality gates.

`uv run ceh skills validate` passes for the operating skill and both candidates. This checks structure only. It is not runtime,
agent-invocation or rendered-quality evidence. Neither candidate has a rendered benchmark or verified agent invocation yet.
The examples are illustrative plans, not playable videos or production job specifications.

## Festive and Indian-festival gap

Live `ceh search festive-cultural-videos --json` and `ceh search indian-regional-festival-content --json` both return empty arrays.
The new skills do not close that gap. They supply general production guidance without claiming cultural correctness or local-language
shaping support. A festival greeting additionally requires approved copy, culturally appropriate artwork, rights-verified music,
localisation review, and an actual output benchmark.

Promising existing investigation candidates, not approved festive capabilities:

- CEH-0018 for reusable motion principles and restrained entrances. It does not supply verified festival content.
- CEH-0012 cth9191/animate for the historically recorded style-grammar/hand-drawn exploration. Its cultural suitability and execution
  compatibility require separate review; no upstream scripts were run for this report.
- CEH-0024 video-shotcraft for the registered storyboard/cinematography workflow. Registration is not evidence of festival accuracy,
  asset clearance or rendered quality.

Next useful evaluation: a brief with owner-approved festival copy and local licensed assets, using the existing HyperFrames engine
and one candidate planning skill in an isolated test project. Record script shaping, legibility, timing and cultural-review verdicts
separately. Do not substitute a decorative colour palette for verified regional knowledge.

## Evidence caveat

The inherited registry marks no-checkout lab clones as having deleted worktree files. For example, CEH-0018 lists all 20 git-tracked
files as deleted even though its git objects are readable and no checkout was performed. These flags should not be interpreted as
proof of user changes or semantic merge conflicts. This issue was reported to the coordinating agent; this curation work does not
change registry records or upstream pins.
